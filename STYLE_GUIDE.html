Typography

Archivo Black is the display face reserved for major headings elsewhere in the app — the menu screen itself never uses it. Inter carries every label, price and line of copy you see below. Nearly every piece of UI chrome is set uppercase, bold and letter‑spaced; only prices and free text stay sentence‑case.

Thumbnail treatments

Two crop languages coexist by context: sharp squares for dense list‑browsing, rounded squares for carousel/card contexts. Both use object-fit: cover.

Design principles

Monochrome‑first

Color carries almost no signal — black, white, grey do the work. The only warmth is the placeholder art behind product photos.

Uppercase is the label voice

Any UI chrome — tabs, pills, section titles, product names, badges — is uppercase and letter‑spaced. Sentence‑case is reserved for prices and free text.

Two radius languages

Sharp squares for dense browsing, soft pills/cards for promotional or carousel contexts. Radius communicates context, not just taste.

Feedback via opacity

Hover and active states dim rather than recolor — opacity: .7 / .5 on rows, no color shifts.

Full field‑by‑field values live in STYLE_GUIDE.md, alongside this board, in the project root.
